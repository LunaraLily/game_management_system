# 游戏管理系统 (Game Management System)

## 项目简介
基于 Django 传统服务端渲染（MVT 架构）开发的 Web 游戏管理系统，
页面由 Django 模板引擎直接渲染输出，非前后端分离架构。

## 核心功能
- **用户鉴权**：未登录/注册用户访问系统会自动跳转至登录/注册页面。
- **游戏管理**：登录成功后，支持对游戏信息进行增删改查（CRUD）。
- **公司管理**：支持对游戏公司信息进行编辑和管理。

## 技术栈
- 后端框架：Django
- 模板引擎：Django Template（HTML + 模板语法）
- 数据库：MySQL
- 架构模式：MVT / 服务端渲染（SSR）
